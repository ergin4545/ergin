# NICO AI Assistant

NICO, Gemini yapay zekâ modeliyle çalışan kişisel bir AI asistanıdır.

## Özellikler
- 🤖 Gemini AI desteği
- 💬 Gerçek zamanlı sohbet
- 📷 Fotoğraf yükleme desteği
- 🔒 Cloudflare Worker ile güvenli API kullanımı
- 📱 PWA desteği
- 💾 Sohbet geçmişi

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript
- Cloudflare Workers
- Google Gemini API
- LocalStorage
- Progressive Web App (PWA)

## Dosyalar
- index.html
- style.css
- app.js
- storage.js
- manifest.json
